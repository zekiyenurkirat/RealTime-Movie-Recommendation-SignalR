# 🎬 Real-Time Movie Recommendation Platform

A dynamic and interactive web application that provides real-time movie recommendations and user interactions using modern backend technologies.

## 🚀 Core Features
* **Real-Time Communication:** Integrated with **SignalR** to push instant updates and recommendations to connected clients without page reloads.
* **Interactive UI:** Smooth and responsive user experience built on the MVC architecture.

## 🛠️ Tech Stack
* **Backend:** C#, ASP.NET Core
* **Real-Time Engine:** SignalR (Hubs integration)
* **Frontend:** HTML, CSS, JavaScript
* **Architecture:** MVC Pattern
